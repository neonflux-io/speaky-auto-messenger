# Speaky Auto Messenger

A Chrome extension that helps you connect with language partners on [Speaky](https://web.speaky.com/) by automating the initial contact message process.

## Features

- 🚀 **Automatic Messaging**: Send personalized messages to multiple users with one click
- 💬 **Message Templates**: Choose from pre-defined templates or create your own custom message
- 🔄 **Progress Tracking**: Monitor messaging progress in real-time
- 🔔 **Notifications**: Get notified when messages are sent
- 🎨 **User-friendly Interface**: Clean and intuitive design
- 🔒 **History Management**: Keep track of users you've already messaged

## Installation

1. Download or clone this repository
2. Open Chrome and navigate to `chrome://extensions/`
3. Enable "Developer Mode" in the top-right corner
4. Click "Load unpacked" and select the downloaded/cloned folder
5. The extension is now installed and ready to use!

## How to Use

1. Go to [Speaky](https://web.speaky.com/) and search for language partners
2. Click the Speaky Auto Messenger extension icon in your browser toolbar
3. Customize your message or select a template
4. Set the number of messages you want to send and the delay between messages
5. Click "Start Messaging" to begin the automated process
6. You can see the progress in real-time and will be notified when messages are sent

## Settings

- **Message Text**: Your personalized message to send to users
- **Personalization**: Automatically adds user's name to your message when available
- **Message Limit**: Control how many messages to send in one session
- **Delay**: Set the time between messages (3-30 seconds)
- **Message History**: Option to clear your message history

## Responsible Use

This extension is designed to help language learners connect more efficiently, but please use it responsibly:

- Don't send the same message to too many users at once
- Personalize your messages whenever possible
- Respect Speaky's community guidelines
- Be genuine in your interactions
- Respond to replies personally, not using automation

## Technical Details

The extension consists of:
- Popup UI for configuration and control
- Content script that interacts with the Speaky website
- Background script for handling notifications and state
